## Features
- Foliage and cobwebs will appear randomly on configured types of blocks (by default on planks, terracotta, etc..)
- Stone bricks will crack over time, but players can reverse this with clay and shovel
- All of this will happen even when chunks are unloaded ("catchup" feature)

Every feature is configurable! See full config here: [config.yml](https://github.com/lisyakteam/overgrown/blob/main/src/main/resources/config.yml)

Supports <b>Folia</b> & <b>Paper</b>, tested on <b>Minecraft Java 26.2</b>!
